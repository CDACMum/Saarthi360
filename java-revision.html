What is Java? Why Java?

🏪

Analogy: Java is like a Universal Outlet Adapter

When you travel from India to Europe, your Indian charger won't fit directly. You need a universal adapter. Java does the same — you write code once and it runs on Windows, Linux, Mac, Android — anywhere! This is Write Once, Run Anywhere (WORA).

🧱 Compiled

Java code (.java) → compiled to bytecode (.class), not machine code directly

🔒 Strongly Typed

Every variable must have a declared type. No implicit type conversions between incompatible types

🌐 Platform Independent

Bytecode runs on JVM. JVM exists for every OS — so your code is OS-agnostic

🧹 Garbage Collected

No manual memory management (unlike C/C++). JVM auto-reclaims unused objects

🔒 Secure

No pointer arithmetic. Class loader, bytecode verifier, and security manager protect runtime

🧵 Multi-threaded

Built-in support for concurrent programming via Thread and Runnable

JVM, JDK, JRE — The Holy Trinity

JDK contains JRE; JRE contains JVM. Developers need JDK; users only need JRE.

Once printed, your Aadhaar card doesn't change. If you need an updated address, UIDAI prints a new card — the old one is discarded. Java's String works the same: every modification creates a new String object. The old one stays in the String Constant Pool until garbage collected.

🚫 Never use == to compare Strings!
str1 == str2 compares references (memory addresses), not content!
Always use str1.equals(str2) to compare content.

Encapsulation — The Capsule Analogy

💊

Analogy: Encapsulation is like a Medicine Capsule

Inside a capsule is the actual medicine powder. You don't touch the powder directly — you swallow the capsule. The outer shell (class) controls access. In Java: private fields = powder inside; public getters/setters = the capsule shell.

public class BankAccount {
    private double balance;     // hidden — no direct access
    private String accountNo;

    // Constructor
    public BankAccount(String accNo, double initialBalance) {
        this.accountNo = accNo;
        this.balance = initialBalance;
    }

    // Getter — read-only controlled access
    public double getBalance() { return balance; }

    // No direct setter for balance! Use controlled methods
    public void deposit(double amount) {
        if (amount > 0) balance += amount; // validation inside
    }
    public boolean withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount; return true;
        }
        return false; // insufficient funds
    }
}

// Usage
BankAccount acc = new BankAccount("SBI-9876", 50000);
acc.deposit(10000);
System.out.println(acc.getBalance()); // 60000.0
// acc.balance = -999; ← COMPILE ERROR — protected!

Inheritance — IS-A Relationship

public class Employee {
    protected int id;
    protected String name;
    protected double salary;

    public Employee(int id, String name, double salary) {
        this.id = id; this.name = name; this.salary = salary;
    }
    public void work() { System.out.println(name + " is working"); }
    public double getSalary() { return salary; }
}

public class Manager extends Employee {
    private int teamSize;

    public Manager(int id, String name, double salary, int teamSize) {
        super(id, name, salary); // call parent constructor
        this.teamSize = teamSize;
    }

    @Override
    public void work() {
        super.work();  // parent's work() called first
        System.out.println(name + " also manages " + teamSize + " people");
    }

    @Override
    public double getSalary() {
        return salary + (salary * 0.20); // manager gets 20% bonus
    }
}

Session 6: Exception Handling

2T + 2L + 2SL hours
S6
🟢 Beginner 🟡 Intermediate 🔴 Advanced
🚦

Analogy: Exception = Traffic Accident on Mumbai-Pune Expressway

You're driving smoothly (program running). Suddenly there's an accident (exception). You have 3 choices: 1) A traffic cop handles it (try-catch), 2) You inform highway authority and they handle it (throws), 3) Regardless of accident, you pay the toll (finally block always runs).

// try-catch-finally: Bank withdrawal example
public void withdraw(double amount) {
    try {
        if (amount <= 0) throw new IllegalArgumentException("Amount must be positive");
        if (amount > balance) throw new InsufficientFundsException("Low balance");
        balance -= amount;
        System.out.println("₹" + amount + " withdrawn");
    } catch (IllegalArgumentException e) {
        System.out.println("Invalid amount: " + e.getMessage());
    } catch (InsufficientFundsException e) {
        System.out.println("Error: " + e.getMessage());
    } finally {
        System.out.println("Transaction attempt logged."); // ALWAYS runs
    }
}

// Custom Exception class
public class InsufficientFundsException extends Exception { // checked
    public InsufficientFundsException(String message) {
        super(message);
    }
}

// throws keyword — delegate exception to caller
public void readFile(String path) throws IOException {
    FileReader fr = new FileReader(path); // let caller handle
}

// try-with-resources (Java 7+) — auto-close resources
try (FileReader fr = new FileReader("data.txt");
     BufferedReader br = new BufferedReader(fr)) {
    String line;
    while ((line = br.readLine()) != null) System.out.println(line);
} // fr and br auto-closed even if exception occurs!

Generics — Type-Safe Containers

📮

Analogy — Government Form with Type Specified

Without generics: a form that accepts ANY document (you might accidentally submit your grocery list as a tax return — caught at runtime). With generics: a form that says "ONLY accept ITR-1 documents" — wrong doc rejected at the counter (compile time). Generics = compile-time type safety.

// Before Generics (old code) — dangerous!
List rawList = new ArrayList();
rawList.add("Hello");
rawList.add(42);  // no error at compile — disaster at runtime!
String s = (String) rawList.get(1);  // ClassCastException at runtime!

// With Generics — safe!
List<String> safeList = new ArrayList<>();
safeList.add("Hello");
// safeList.add(42);  ← COMPILE ERROR! Type-safe
String safe = safeList.get(0);  // no cast needed!

// Generic Class
public class Repository<T> {
    private List<T> store = new ArrayList<>();
    public void save(T item) { store.add(item); }
    public T findById(int idx) { return store.get(idx); }
    public List<T> findAll() { return Collections.unmodifiableList(store); }
}

Repository<Employee> empRepo = new Repository<>();
empRepo.save(new Employee(1, "Priya", 80000));
Employee e = empRepo.findById(0);  // no cast! T=Employee

// Bounded Wildcards
public static double sumSalaries(List<? extends Employee> list) {
    return list.stream().mapToDouble(Employee::getSalary).sum();
}  // accepts List<Employee>, List<Manager>, List<Developer>

// <? super Manager> = Manager or any parent type

Enums — Smart Named Constants

🚦

Analogy — Traffic Signal States

A traffic light can ONLY be RED, YELLOW, or GREEN. You can't have it be PURPLE or 42. enum restricts a variable to a fixed set of constants — no magic numbers, no invalid states, clean switch statements.

// Basic Enum — type-safe constants
public enum Season { SUMMER, MONSOON, WINTER, SPRING }

// Power Enum — with fields, constructors, methods
public enum EmployeeType {
    PERMANENT(1.0, "Full Benefits"),
    CONTRACT(0.85, "Limited Benefits"),
    INTERN(0.5, "Stipend Only");

    private final double salaryFactor;
    private final String benefits;

    EmployeeType(double factor, String benefits) {
        this.salaryFactor = factor;
        this.benefits = benefits;
    }
    public double getSalaryFactor() { return salaryFactor; }
    public String getBenefits() { return benefits; }
    public boolean isFullTime() { return this == PERMANENT; }
}

// Days enum with logic
public enum Day {
    MON, TUE, WED, THU, FRI, SAT, SUN;
    public boolean isWeekend() { return this == SAT || this == SUN; }
    public boolean isWeekday() { return !isWeekend(); }
}

// Usage
EmployeeType type = EmployeeType.CONTRACT;
double ctc = 60000 * type.getSalaryFactor(); // 51000
System.out.println(type.getBenefits());       // Limited Benefits
System.out.println(type.name());              // "CONTRACT"
System.out.println(type.ordinal());           // 1 (0-indexed position)

// Switch with Enum (very clean)
switch (type) {
    case PERMANENT: System.out.println("PF + Gratuity + Insurance"); break;
    case CONTRACT:  System.out.println("Basic Insurance"); break;
    case INTERN:    System.out.println("Stipend: ₹15,000"); break;
}

// Enum iteration
for (EmployeeType t : EmployeeType.values()) {
    System.out.println(t + ": " + t.getSalaryFactor());
}
EmployeeType fromStr = EmployeeType.valueOf("INTERN"); // parse from String

Session 10 · Functional Programming & Lambda Expressions

2T + 2L hours
S10
🟡 Intermediate🔴 Advanced
📦

Analogy — Zomato Delivery Instructions Without Naming Delivery Partner

"Deliver this order, ring the bell twice, leave at door." — You describe the behaviour, not the person. Lambda expressions are exactly this: behaviour passed as data. No need to create a whole class — just write what to DO as a compact expression.

import java.util.function.*;

// ── Functional Interfaces from java.util.function ──

// Predicate<T> — test a condition → returns boolean
Predicate<Integer> isSenior = salary -> salary > 75000;
Predicate<String>  isNonEmpty = s -> !s.isBlank();
Predicate<Integer> isHigh = salary -> salary > 100000;
// Compose predicates
Predicate<Integer> midRange = isSenior.and(isHigh.negate()); // 75001-99999
System.out.println(isSenior.test(80000));    // true
System.out.println(midRange.test(80000));    // true

// Function<T,R> — transform T to R
Function<String, Integer> strLen = String::length;   // method reference
Function<Integer, String> rupeeFormat = n -> "₹" + String.format("%,d", n);
Function<String, String> combined = strLen.andThen(rupeeFormat); // chain functions
System.out.println(strLen.apply("C-DAC"));   // 5
System.out.println(rupeeFormat.apply(85000)); // ₹85,000

// Consumer<T> — use T, return nothing (side effects)
Consumer<String> logger = msg -> System.out.println("[LOG] " + msg);
Consumer<Employee> raiseHike = emp -> emp.setSalary(emp.getSalary() * 1.1);
logger.accept("System started");

// Supplier<T> — produce T, takes no input
Supplier<String> idGen = () -> "EMP-" + (int)(Math.random() * 9000 + 1000);
Supplier<List<String>> listFactory = ArrayList::new;  // constructor ref
System.out.println(idGen.get());  // EMP-4752

// BiFunction<T,U,R> — two inputs, one output
BiFunction<String, Double, String> offerLetter =
    (name, sal) -> "Dear " + name + ", CTC: ₹" + sal;
System.out.println(offerLetter.apply("Priya", 85000.0));

// UnaryOperator — T → T (same type in and out)
UnaryOperator<String> trimUpper = s -> s.trim().toUpperCase();
System.out.println(trimUpper.apply("  cdac kharghar  ")); // C-DAC KHARGHAR

// Method References — 4 types
static method ref:     Math::sqrt               // ClassName::staticMethod
instance method ref:   String::toUpperCase       // ClassName::instanceMethod
instance on obj ref:   System.out::println       // obj::instanceMethod
constructor ref:       ArrayList::new            // ClassName::new

Sessions 11–12 · Stream API & Java 8 Date-Time API

4T + 4L + 2SL hours
S11–S12
🟡 Intermediate🔴 Advanced
🏭

Analogy — Amazon Fulfillment Centre Assembly Line

Orders (data) enter the belt. Station 1 filters defective items (filter). Station 2 relabels them (map). Station 3 sorts by delivery zone (sorted). Final packing (collect). The belt is LAZY — it doesn't run until someone says "dispatch!" (terminal operation). Workers don't keep all items in memory — they process one at a time (stream is not storage).

import java.util.stream.*;
import java.util.*;

List<Employee> emps = getEmployees();

// ── 1. filter + map + collect ──
List<String> seniorNames = emps.stream()
    .filter(e -> e.getSalary() > 70000)         // keep seniors
    .filter(e -> e.getDepartment().equals("IT")) // in IT dept
    .map(Employee::getName)                       // extract names
    .sorted()                                     // alphabetical
    .distinct()                                   // no duplicates
    .limit(10)                                    // top 10 only
    .collect(Collectors.toList());

// ── 2. Aggregation operations ──
double totalSalary = emps.stream()
    .mapToDouble(Employee::getSalary)
    .sum();                               // total payroll

OptionalDouble avg = emps.stream()
    .mapToDouble(Employee::getSalary)
    .average();                           // returns Optional (might be empty stream)
avg.ifPresent(a -> System.out.printf("Avg: ₹%.2f%n", a));

double maxSalary = emps.stream()
    .mapToDouble(Employee::getSalary)
    .max().orElse(0);

long count = emps.stream()
    .filter(e -> e.getSalary() > 80000)
    .count();

// ── 3. Matching ──
boolean anyManager = emps.stream().anyMatch(e -> e instanceof Manager);
boolean allPaid    = emps.stream().allMatch(e -> e.getSalary() > 0);
boolean noneNeg    = emps.stream().noneMatch(e -> e.getSalary() < 0);

// ── 4. reduce — custom aggregation ──
double total = emps.stream()
    .mapToDouble(Employee::getSalary)
    .reduce(0, Double::sum);

// ── 5. Collectors — powerful terminal ops ──
// Group employees by department
Map<String, List<Employee>> byDept = emps.stream()
    .collect(Collectors.groupingBy(Employee::getDepartment));

             Collectors.averagingDouble(Employee::getSalary)));

    }

// Way 2: Implement Runnable (PREFERRED — allows other inheritance)
Runnable task = () -> {
    for (int i = 0; i < 3; i++) {
        System.out.println(Thread.currentThread().getName() + ": " + i);
    }
};
Thread t1 = new Thread(task, "Teller-1");
Thread t2 = new Thread(task, "Teller-2");
t1.start(); t2.start();

// Synchronization — prevent race condition on shared bank account
public class SafeAccount {
    private double balance = 100000;

    public synchronized void withdraw(double amount) {
        if (balance >= amount) {
            System.out.println(Thread.currentThread().getName()
                + " withdrawing ₹" + amount);
            balance -= amount;
        }
    }
}
// synchronized ensures only ONE thread at a time modifies balance
🚨 Race Condition = Corrupted Data!
Without synchronization, two threads reading balance simultaneously, both seeing ₹1000, both withdrawing ₹800 — account goes negative! Always synchronize shared mutable state.

Complete CRUD Example

import java.sql.*;

public class EmployeeDAO {
    private static final String URL = "jdbc:mysql://localhost:3306/cdac_db";
    private static final String USER = "root";
    private static final String PASS = "cdac@123";

    // Establish connection
    private Connection getConnection() throws SQLException {
        return DriverManager.getConnection(URL, USER, PASS);
    }

    // CREATE — PreparedStatement prevents SQL Injection
    public void insertEmployee(Employee emp) {
        String sql = "INSERT INTO employees(name, salary, dept) VALUES(?,?,?)";
        try (Connection conn = getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, emp.getName());
            ps.setDouble(2, emp.getSalary());
            ps.setString(3, emp.getDepartment());
            int rows = ps.executeUpdate();
            System.out.println(rows + " row(s) inserted");
        } catch (SQLException e) { e.printStackTrace(); }
    }

    // READ — SELECT with ResultSet
    public List<Employee> getAllEmployees() {
        List<Employee> list = new ArrayList<>();
        String sql = "SELECT * FROM employees";
        try (Connection conn = getConnection();
             Statement stmt = conn.createStatement();
             ResultSet rs = stmt.executeQuery(sql)) {
            while (rs.next()) {
                Employee e = new Employee(
                    rs.getInt("id"),
                    rs.getString("name"),
                    rs.getDouble("salary")
                );
                list.add(e);
            }
        } catch (SQLException e) { e.printStackTrace(); }
        return list;
    }

    // UPDATE
    public void updateSalary(int id, double newSalary) {
        String sql = "UPDATE employees SET salary=? WHERE id=?";
        try (Connection conn = getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setDouble(1, newSalary);
            ps.setInt(2, id);
            ps.executeUpdate();
        } catch (SQLException e) { e.printStackTrace(); }
    }

    // DELETE
    public void deleteEmployee(int id) {
        String sql = "DELETE FROM employees WHERE id=?";
        try (Connection conn = getConnection();
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setInt(1, id);
            ps.executeUpdate();
        } catch (SQLException e) { e.printStackTrace(); }
    }
}

Transaction Management

// ACID: transfer ₹10,000 from Priya to Rahul
Connection conn = getConnection();
try {
    conn.setAutoCommit(false);  // BEGIN TRANSACTION

    PreparedStatement debit = conn.prepareStatement(
        "UPDATE accounts SET balance=balance-? WHERE id=?");
    debit.setDouble(1, 10000); debit.setInt(2, priyaId);
    debit.executeUpdate();

    PreparedStatement credit = conn.prepareStatement(
        "UPDATE accounts SET balance=balance+? WHERE id=?");
    credit.setDouble(1, 10000); credit.setInt(2, rahulId);
    credit.executeUpdate();

    conn.commit();  // BOTH succeed → commit
    System.out.println("Transfer successful!");
} catch (SQLException e) {
    conn.rollback(); // ANY failure → undo both
    System.out.println("Transfer failed — rolled back");
} finally {
    conn.setAutoCommit(true);
    conn.close();
}

Exam Quick Reference — Key Concepts Summary

🔑 Important Keywords

static final abstract synchronized extends implements interface throws throw try/catch/finally transient volatile

⚡ Access Modifiers (Widest → Narrowest)

public → everyone
protected → package + subclasses
(default) → same package only
private → same class only

🧠 "this" vs "super"

this → refers to current object's members; this() calls another constructor in same class.
super → refers to parent class members; super() calls parent constructor — must be first line!

🔒 final keyword (3 uses)

final variable = constant (can't reassign)
final method = can't override in child
final class = can't extend (e.g., String is final!)

🗑️ static keyword (3 uses)

static variable = shared by all objects (class variable)
static method = called without object (e.g., Math.sqrt())
static block = runs once when class loaded

💡 Common Tricky Questions

• Can constructors be private? → Yes (Singleton pattern)
• Can abstract class have constructor? → Yes
• Interface can extend multiple interfaces? → Yes
• Can we override static methods? → No (method hiding)
• What if main() throws exception? → JVM terminates
